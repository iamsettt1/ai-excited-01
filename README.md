A colossal blue whale breaches out of a night ocean and arcs diagonally up toward a giant golden ringed planet hanging low in the sky, its spout streaming light toward the ring, while a tiny city below cheers with searchlights and confetti under aurora ribbons and stars. The program draws the whole scene pixel by pixel — sky, stars, aurora, planet, whale, sea, city, confetti — with the Node standard library alone, and writes the single image to `/output/entry.png`, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
