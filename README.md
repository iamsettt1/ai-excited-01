A colossal blue whale breaches out of a night ocean and arcs up toward a giant golden ringed planet hanging low in the sky, its spout streaming light toward the ring while a tiny city below cheers with searchlights and confetti. The program draws the whole scene from code — sky, aurora, planet, whale, city and spray — with a small deterministic software rasterizer and a hand-written PNG encoder, using only the Node standard library, so two runs produce byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
