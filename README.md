A colossal blue whale breaches out of a glowing night ocean and arcs diagonally up toward a giant golden ringed planet hanging in a starry violet sky, its spout streaming light toward the ring, spray and foam bursting where it tore out of the water. The program draws the whole scene pixel by pixel — sky, stars, shooting stars, planet and rings, sea, whale, splash — with the Node standard library alone, and writes the single image to `/output/entry.png`, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
